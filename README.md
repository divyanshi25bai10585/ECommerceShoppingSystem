## Project Overview

The E-Commerce Shopping and Order Management System is a Java-based
command-line application that simulates the basic operations of an
online shopping platform.

The system allows users to register, login, browse products, search
products, manage a shopping cart, place and track orders, generate
bills, make simulated payments, save order information, and receive
product recommendations.

## Features

- User Registration and Login
- Product Management
- Product Search
- Shopping Cart Management
- Order Placement
- Order Tracking
- Billing
- UPI, Card and Cash on Delivery Payment Simulation
- Order Data File Storage
- Smart Product Recommendations
- System Testing

## Main Modules

1. User Management
2. Product Management
3. Shopping Cart
4. Order Management
5. Billing and Payment
6. File Storage
7. Recommendation Engine
8. System Testing
