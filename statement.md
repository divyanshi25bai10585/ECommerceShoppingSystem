## 1. Problem Statement

Online shopping systems involve multiple activities such as user
registration, product browsing, searching, cart management, order
placement, billing, payment and order tracking.

The purpose of this project is to develop a Java-based command-line
E-Commerce Shopping and Order Management System that combines these
operations into one integrated application.

## 2. Objectives

The main objectives of the project are:

- To provide user registration and login functionality.
- To allow users to browse and search products.
- To provide shopping cart management.
- To enable order placement and order tracking.
- To generate bills for purchases.
- To simulate different payment methods.
- To store order information using file handling.
- To provide product recommendations.
- To demonstrate object-oriented programming concepts.

## 3. Functional Requirements

### User Management
The system shall allow users to register and login.

### Product Management
The system shall display available products and allow users to search
for products.

### Shopping Cart
The system shall allow users to add products and quantities to the
shopping cart and view the cart total.

### Order Management
The system shall allow users to place orders and view order details.

### Order Tracking
The system shall allow users to track an order using its Order ID.

### Billing and Payment
The system shall generate a bill and provide simulated UPI, Card and
Cash on Delivery payment options.

### File Storage
The system shall save order information in a text file.

### Recommendation
The system shall suggest related products based on the selected
product.

## 4. Non-Functional Requirements

### Performance
The system should respond quickly to user commands.

### Usability
The command-line interface should be simple and easy to understand.

### Reliability
The system should handle invalid product IDs and invalid quantities
without crashing.

### Maintainability
The application should be divided into separate classes and modules
for easier maintenance.

### Error Handling
The system should display appropriate messages for invalid input and
unsuccessful operations.

### Resource Efficiency
The application should use simple Java data structures and file
handling without unnecessary resource consumption.
